cangui — CAN Network GUI
========================

**cangui** is a CAN Network GUI application built with PySide6, following
PCAN Explorer's UI patterns: table-based RX/TX views, 3-pane tabbed layout,
hex view, connections management, UDS diagnostics, and signal plotting.
